# BourbonSense website

The public landing page and user guide for BourbonSense, a private tasting journal for bourbon (iPhone and Android).

- `index.html`: landing page (features, privacy, FAQ)
- `guide.html`: how to use the app
- `styles.css`: the app's letterpress design, light and dark
- `images/`: screenshots from the app (light and dark) and icons
- `fonts/`: Rye, Libre Caslon Text and Courier Prime (SIL Open Font License), served from this site

Static files, no build step and no third-party requests (no analytics, no web fonts from elsewhere). Published with GitHub Pages from `main`.

Later (BourbonSense M2.4) this site also serves `bourbonsense.app`: the shared-note viewer at `/n` and the app-link files in `/.well-known/`.
